# SEO y GEO de Escáner JW

La URL canónica prevista para GitHub Pages es `https://laotracaradelatorre.github.io/extractorjw/` porque el repositorio es `laotracaradelatorre/extractorjw`.

## Archivos incluidos
- `index.html`: metadatos SEO, Open Graph, Twitter, canonical, hreflang, contenido explicativo visible y datos estructurados JSON-LD.
- `robots.txt`: permite rastreo público e indica el sitemap.
- `sitemap.xml`: declara la URL canónica.
- `llms.txt`: resumen legible para sistemas de IA; es una ayuda opcional, no un estándar que garantice inclusión.
- `site.webmanifest`: metadatos básicos de aplicación.
- `assets/logo.jpg`: logo accesible por URL para iconos y previsualizaciones.

## Publicación
Subí todos estos archivos y carpetas a la raíz del repositorio `extractorjw`, conservando la estructura. Activá GitHub Pages desde Settings → Pages → Deploy from a branch → main → /(root).

## Verificación posterior
1. Abrí `https://laotracaradelatorre.github.io/extractorjw/` y comprobá que carga.
2. Abrí `https://laotracaradelatorre.github.io/extractorjw/robots.txt`, `https://laotracaradelatorre.github.io/extractorjw/sitemap.xml` y `https://laotracaradelatorre.github.io/extractorjw/llms.txt`.
3. Añadí y verificá la propiedad en Google Search Console y Bing Webmaster Tools.
4. En Search Console, inspeccioná la URL principal y enviá `https://laotracaradelatorre.github.io/extractorjw/sitemap.xml`.
5. Validá JSON-LD con Rich Results Test / Schema Markup Validator.

## Nota sobre GEO
Se incorporó contenido claro, una definición directa, identidad editorial, independencia, fuente primaria, límites de funcionamiento y datos estructurados consistentes con el contenido visible. Ninguna etiqueta o archivo garantiza citas en buscadores generativos; la claridad, la utilidad, la reputación y las menciones externas también importan.
